Cache v0.9.0

June 06, 2026

← Changelog

What's New

  • Added word jumping (Cmd/Ctrl+G) — type a two-letter label to move the cursor to any visible word
  • Improved Chinese, Japanese, and Korean text — cursor, selection, and navigation now align correctly
  • Improved emoji rendering — families, flags, and skin-tone emoji now stay whole
  • Improved filenames generated from note titles — hyphens and underscores now separate words, with accent support
  • Improved the sync reminder so it skips the note you're actively editing
  • Improved Git remote setup with clearer guidance when an SSH URL is entered
  • Fixed onboarding occasionally stalling after cloning your repository for the first time
  • Fixed onboarding getting stuck on a directory the app can't write to — you're now prompted to re-grant access
  • macOS: Fixed cloning a repository during setup
  • Fixed a crash when pressing backspace during text composition (e.g. accented or CJK input)
  • Fixed continuation suggestions for lists, tasks, and tables sometimes not appearing
  • Fixed hidden characters that could misplace the cursor or slip in while typing
  • Fixed stray boxes and false change warnings in notes from other apps
  • Fixed paragraph navigation stopping at lines that contain only indentation
  • Fixed the virtual-keyboard Shift key changing case on the wrong word
  • macOS: Removed unused window tab options from the View menu
